# Voyage Analytics: Integrating MLOps in Travel

Capstone project — flight price regression model, served via Flask REST API, containerized with Docker, deployed on Kubernetes.

## Structure
See project folders: data/, notebooks/, models/, src/, api/, docker/, k8s/, tests/, reports/

## Setup
```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
```
